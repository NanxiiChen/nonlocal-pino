# Fracture2D 阶段性记录：接受未收敛状态后继续加载

记录日期：2026-10-12。本文固定记录本次已完成的实验；后续进展、阻碍和续算点以[当前任务](../tasks/fracture2d-nonlocal-pinn.md)为准。

## 本阶段的发现

从未收敛的加载位移 0.0053 继续推进到 0.0075，PINN 的裂纹持续扩展、反力总体下降，但仍未贯通。相同起点、每步同样限制为 8 次交替更新的直接损伤对照，在 0.0074 才出现贯通；充分收敛的同模型直接参考在 0.0053 已贯通。

**这次结果值得保留的原因是：直接求解在提前提交状态、限制每步交替更新次数后，也表现出明显的开裂滞后。当前困难因此不能全部归因于 PINN 或某一种优化器。** PINN 相对于该直接对照还有额外的滞后，需继续分析损伤求解误差及其对后续历史场的反馈。

以上是有限迭代预算下的观察。本次没有证明优化器无法求解 0.0053 的开裂状态，也没有证明提高加载后可获得仅有轻微临界位移偏移的收敛解。

## 实验问题与提交策略

用户提出：当前 0.0053 的裂纹已经沿合理方向扩展，能否暂时接受这个状态、继续加载，检查更高加载是否会让裂纹快速贯通？允许一定程度的开裂滞后。

本阶段为此创建独立的探索分支。原有严格验收通过的 1–52 步保持完整；新的 53–75 步标记为 `user_provisional`。允许有限、满足损伤范围和力学平衡检查的状态在损伤方程或耦合收敛检查未通过时继续加载。原检查及失败数值仍保存，未把这些状态改称为收敛解。非有限值、损伤范围或力学平衡失败仍会停止计算。

本次 PINN 和同预算直接对照的加载路径均计算完成，计算进程已退出。

## 模型和计算设置

本阶段使用直接局部 P1 平面应变力学，以及非局部 AT2 损伤算子。力学直接求解，PINN 表示并求解损伤；它与此前全非局部 A2 力学分支是不同的模型。

| 项目 | 本次设置 |
|---|---|
| 材料参数 | \(E=210000\)，\(\nu=0.3\)，\(G_c=2.7\)，\(k_{res}=10^{-8}\) |
| 相场长度、损伤支持半径 | \(l_0=0.024\)，\(\delta_d=0.008\) |
| 力学 | 原始局部 P1 FEM、体积夹持边界、原始反力计算 |
| 历史场 | \(H=\max(H_{n-1},\psi^+(u))\)，\(H_{n-1}\) 为上一加载步已提交值 |
| 损伤网络 | 已有历史场特征 MLP 与紧支撑读出，线性输出、warm start |
| 内循环 | 当前 \(H\) 及其特征冻结并停止梯度，全域缓存残差 L-BFGS |
| 外循环松弛 | \(\omega=0.5\) |
| 加载 | 起始第 53 步 0.0053；新增第 54–75 步，步长 0.0001 |
| 每加载步外循环 | 最多 8 次；本次所有新增步实际均为 8 次 |
| PINN 每次内循环 | 每个罚参数阶段最多 512 次更新，保留原始提前退出检查 |
| 损伤范围 | \([-0.001,1+2\times10^{-6}]\)，保留有符号值，无输出裁剪 |
| 范围处理 | 原有增广拉格朗日方法；罚参数序列 \(10^3,10^4,10^5,10^6\) |

原非局部损伤残差继续使用：

$$
r_d=\frac{G_c}{l_0}d+G_cl_0Dd+2H(d-1),\qquad D\approx-\nabla^2.
$$

表中 512 次是每个罚参数阶段的上限：范围不合格时可继续下一阶段，并非任何情况下每次内循环总共只能执行 512 次。原方程、几何、算子、历史场更新和范围检查未修改；没有直接损伤标签、节点损伤修正或参考值输出。

起点为前一实验中 sampled Adam 后经过全域 L-BFGS 收尾的网络，以及按原 \(\omega=0.5\) 更新得到的物理候选状态。该状态在 0.0053 的反力为 535.536512，已独立复核但未通过耦合收敛验收。**本次新增加载训练采用全域 L-BFGS，并未重新运行随机 Adam 或随机采样。**

## 三组结果及比较边界

| 分支 | 起点与损伤求解 | 每步交替更新 | 高损伤带首次贯通 |
|---|---|---|---|
| 本次 PINN | 未收敛的 0.0053 状态；神经损伤求解 | 8 次 | 到 0.0075 仍未贯通 |
| 同预算直接损伤对照 | 同一 0.0053 状态；原 AT2 直接 CG | 8 次 | 0.0074 |
| 充分收敛直接参考 | 从零加载；相同物理模型和离散化 | 按原严格收敛检查求解 | 0.0053 |

直接对照仅将损伤求解替换为原有体积加权 SPD 系统的 CG，保留相同起点、加载序列、松弛系数和外循环次数。直接解从未作为 PINN 训练目标。

这里的“贯通”是一个明确的云图诊断：在原 P1 网格边连接上寻找 \(d\ge0.9\) 的连通分量，该分量接触以原裂尖 \((0.5,0.5)\) 为中心、半径 0.024 的区域，并到达右边界 \(x=1\)。它不是新的收敛验收条件；高损伤带贯通仍不等于全部方程与不可逆性检查通过。

同预算直接对照与充分收敛参考的**起始历史路径和提交策略也不同**。本次可证明这一探索策略下直接损伤同样滞后，不能把它与参考的全部差异独立归因于“恰好 8 次”这一单一因素。

损伤误差使用材料节点体积加权相对 \(L^2\)：

$$
e_d=\sqrt{\frac{\sum_iV_i(d_i-d_i^{ref})^2}{\sum_iV_i(d_i^{ref})^2}}.
$$

这不是相同冻结历史场下的神经拟合误差；被比较的三条加载路径已经形成不同的自身历史场。即使直接对照贯通，损伤场仍与收敛参考明显不同。

## 收敛与独立复核

PINN 第 53–75 步均未通过原始加载步收敛检查，整条新增路径保持 `certified_path=false`。已提交历史场不降低，但最大跨加载步损伤回退为 0.072131655，发生于第 64 步；第 75 步回退为 0.003822233，均超过原 0.001 门槛。最大历史场并不自动使这些未收敛的神经候选损伤逐点单调。

独立 CPU 复核覆盖两条探索路径的全部 53–75 步，包括保存文件哈希、父状态链、边界位移、原始刚度矩阵自由力平衡、反力、自身历史场、原始损伤算子和裂纹连通诊断。PINN 还独立重算网络输出、冻结历史场残差及更新后历史场下的网络残差；直接对照复核原始体积加权 CG 系统。

这些复核均通过，表示结果可以独立重现，且未隐藏损伤范围或力学失败；**复核通过不表示那些已明确报告为失败的损伤与耦合收敛检查通过。** 此前相关 7 个聚焦测试通过，本次记录仅整理既有结果，没有重新训练或更改求解代码。

GPU 主计算进程正常退出，运行约 29 分 29 秒，含初始化及短暂的直接对照 GPU 重叠；不据此比较求解器速度。

## 阶段性判断与后续检验

1. 继续加载能推动本次 PINN 裂纹扩展，但到 0.0075 还没有获得完整开裂状态。
2. 提前提交、限制交替更新的路径使直接损伤求解也明显滞后；这支持把耦合迭代与加载提交策略纳入困难分析。
3. PINN 相对于同预算直接对照还有明显差异。后续需区分当前历史场下的损伤拟合误差、耦合更新不足和累计历史场反馈，不能仅凭反力下降或云图变亮认定误差已解决。
4. 当前证据不足以把这条路径解释为仅有可接受轻微滞后的收敛解，也不足以断言 Adam、L-BFGS 或随机采样无法求得贯通状态。

建议下一项受控实验为固定 0.0075 增加交替更新，观察贯通与残差变化。恢复时使用第 75 步物理状态和网络，并保留第 74 步提交历史场作为该加载步的历史父状态。不能把第 75 步历史场悄然作为自身父状态，否则改变了该步求解的问题。该实验尚未启动，具体恢复要求见当前任务。
