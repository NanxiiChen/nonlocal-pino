## 模型一致性与尚未解决的困难

固定历史场时，direct 与 PINN 求解同一离散 AT2 方程；其体积加权正定系统有唯一节点解。网络若能表示该解且残差充分降低，应接近 direct。完整耦合过程还受加载历史、分支和内外层精度影响，不能保证任意有限训练轨迹相同。

现有 direct 诊断在 0.005275/outer128 的反力仍为 580.54，outer1024 为 293.90，outer1575 才收敛到约 1.59。当前 PINN 的每步 128 次预算与充分收敛 reference 的比较包含明显的外层推进差异；不能把开裂滞后解释为 PINN 不可消除的物理特性。局部内层误差、累计历史场反馈和网络表示能力仍需分别分析。

下一项有价值的数值对照是统一前一步物理状态、历史场和目标加载，分别控制内层损伤精度及外层收敛，再判断瓶颈。这项新对照和额外 weighting 尚未启动。
