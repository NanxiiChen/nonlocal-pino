# Research site layout prototypes

Goal: propose the content structure and visual design of the five-example
nonlocal PINO research site. Provide three local previews using the current
curated repository figures and verified representative values.

Acceptance: each preview presents the method and five cases in a distinct
reading order. The proposal covers case detail, scientific claim boundaries,
and the later GitHub Pages workflow. Local navigation and assets are checked.

Context: the five main cases are ice melting, electropolish, confined spinodal,
the full coupled NS–CH channel, and ceramic-particle corrosion. The current
repository is private. This phase ends at design review.

Status: design-review deliverable complete. The preview chooser linked the
paper, technical reference and field atlas layouts. The user subsequently
selected the technical reference design, now documented in the
[site guide](../../../website/README.md).

Changes: added four HTML entry pages, one shared stylesheet, and a shared
English preview script with the five curated case summaries. Added the source
directory to the root README structure. Preview figures use existing tracked
assets by relative paths. Screenshots are external visualization artifacts.

Validation: Chromium checked all four pages at 1440, 768, 390 and 320 pixels,
including case anchors, accordions and horizontal fit. All ten scientific
images and five example README targets resolved. Direct browser file opening,
JavaScript syntax and diff whitespace checks passed.

Next phase: take the user's layout selection, develop the five complete case
pages, and configure the allowlisted build. Confirm Pages eligibility and
intended audience before public deployment from the private repository.
No Git history operation or hosting change occurred in the design phase.
