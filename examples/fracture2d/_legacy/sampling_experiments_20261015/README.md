# Archived sampling experiments — 2026-10-15

Source copies of the completed particle-count/resource assessments, density
and batch-hold comparisons, tolerance probe and speed review. These are
run-specific diagnostics, not supported training entry points. Main training
uses `examples.fracture2d.train` with `train_base.py` or `train_core_halo.py`.

The copies retain the original run paths and experiment settings. They do not
import into the public solver. Existing external scripts and run snapshots
remain intact; active GPU-baseline launchers are not moved or altered. Exact
results and limitations are recorded in the active fracture2d task. Historical
replay requires the corresponding saved config/source snapshot and fresh output
paths, rather than rerunning these scripts against an occupied result root.
